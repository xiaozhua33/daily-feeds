一句话总结：今天最重要的是，Cursor 公布了上个月被攻击的完整经过，源头不在它自己，而是交给合作方的一把钥匙，加上智能体会话记录里没删干净的密钥。
今天讲四件事。
第一件，是安全事故。Cursor 十一月十三日发了调查报告。起点在模型服务商 Fireworks：Cursor 发给它的一把访问钥匙被泄露，攻击者用它复制了一个存放编程智能体会话记录的存储桶。这些记录大多来自二零二五年，属于没开隐私模式、允许用来训练的会话。其中少数记录里，有用户贴进去的密钥没被删掉，按 Cursor 的说法，受影响的客户不到万分之一。攻击者顺着这些密钥，进了 Cursor 用的几个办公工具，看到了旧代码库、部分客服邮件，还有用户发给客服的一些登录凭证。十月二十九日，他又用偷来的凭证，把一个带后门的 Claude Code 扩展假版本放进 Cursor 的扩展市场，挂了大约十一个小时，最多五千人可能装到。Anthropic 自己的扩展没有问题。Cursor 已经把推理流量全部撤离 Fireworks，并更换了所有内部凭证。
为什么重要？你在和智能体对话时贴进去的东西，会变成记录，可能被存到第三方那里。一个合作方出事，就能一路连锁。
第二件，也是风险。安全公司 Depi 十一月十一日公开了一条攻击链，对象是 OpenAI 的编程智能体 Codex。OpenAI 自己的代码仓库里，有一个自动给问题单贴标签的流程，它会把任何陌生人写的问题单标题和正文，直接交给 Codex 读。研究者在问题单里藏了一段提示注入，让 Codex 执行了他们的程序，再从沙盒里逃出来，从运行机器的内存里拿到了 GitHub 的令牌，也就是一张能代替密码操作仓库的临时通行证。顺着它，原本可以碰到正式版 Codex 安装包的发布流程。这就是供应链攻击，意思是不直接攻击用户，而是在大家都会下载的软件里提前动手脚。OpenAI 已经修复，用户不需要做什么。
为什么重要？读陌生人文字的智能体，不能和发布钥匙放在一起。研究者还建议，自动更新的工具最好等新版本放几天再装。
第三件，是智能体购物。OpenAI 十一月十三日推出 ChatGPT Wallet，和美国运通、万事达、Visa 合作。你只加一次卡，之后每次购买都要用面容或指纹确认；付款时卡组织给一个替身卡号，智能体和商家都看不到真卡号。目前只给美国的 Pro 用户。同一天，Sierra 发布了个人智能体协议 Poppy 一点零，规定你的智能体到了一家公司的网站，怎么说明自己是谁、能做什么。登录用 OAuth，就是你在对方网站授权、不用把密码交给智能体的那种方式。Shopify 已经给所有店铺自动开启，Meta 的智能体 Muse 每到一个网站都先找它。另一边，据《华尔街日报》援引知情人士报道，摩根大通在拒绝客户把卡号交给智能体代购的交易。欧盟委员会也提议，智能体替人签约时，第一次使用就要问清楚你想授权到什么程度。
为什么重要？智能体代你花钱，正在从拿着账号硬点网页，变成走官方协议、每笔都要你确认。
第四件，是总调度的新做法。谷歌十一月十二日在编程工具 Antigravity 里推出 Orchestrator 模式：大模型先只读不改，摸清情况，写好计划，还写明什么情况下要重新规划；然后交给又快又便宜的 Gemini 4 Hydrogen 动手。小模型遇到麻烦，比如同一步验证失败两次，就把控制权交回大模型修计划。谷歌说，测试里成功率接近只用大模型，额度少用百分之二十四，这是它自己的数据。第二天，Anthropic 也更新了 Claude Code 的项目功能，负责统筹的总调度会主动在聊天里汇报各条并行任务的进度，不用你一个个去查。
为什么重要？大模型规划、小模型干活、卡住就交回，正在变成智能体的标准分工。
今天就到这里，明天见。
